# canton-splice-k8s

A reusable, parametrized Kubernetes base for running a self-contained
Canton/Splice network (participant, domain, scan, SV, validator, Keycloak)
under FluxCD, plus generic DAR-deploy tooling and an admin/debug pod.

Initial content is landing via pull request. See the open PRs for the full base.
